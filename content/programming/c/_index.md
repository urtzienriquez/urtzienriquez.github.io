These are some notes on the `C` programming language. C is the language underneath most of the tools we use in scientific computing: R, Python and Julia all rely on it, and it is still the go-to choice when a piece of code needs to be fast. Learning it is a great way to understand what our computers are actually doing.

As with the other series, **this is a work in progress**, and I will be adding new posts as I go.

Hope this is helpful to someone, and enjoy coding! :)
